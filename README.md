# Assessment 3.4: Non-Linear Data Structure (AMOIN)

This project contains Python implementations of Breadth-First Search (BFS) and Depth-First Search (DFS) for both a Binary Tree and a Graph constructed using the surname **AMOIN** (A, M, O, I, N).

## Options
- **1**: Show binary tree and its traversals
- **2**: Show graph and its traversals
- **3**: Show both
- **0**: Exit

## Running the Code
```bash
python main.py
```
